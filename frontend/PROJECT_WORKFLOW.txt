1. PROJECT OVERVIEW
================================================================================

StatSkill AI is an AI-powered competency management, skill gap assessment, and
personalized learning development platform designed for the Ministry of
Statistics and Programme Implementation (MoSPI), Government of India.

It addresses continuous professional upskilling and competency governance across
India's National Statistical System (NSSO, National Accounts Division, Price
Statistics Division, Field Operations Division).

Core Capabilities:
  • Cadre Competency Diagnostics across 4 official domains
  • AI-Driven Skill Gap Analysis with Radar Chart visualization
  • Personalized Learning Roadmaps with national platform integration
  • Continuous Learning Audit with daily/weekly tracking
  • Cadre Administration & Oversight for leadership

5. COMPLETE OFFICER (EMPLOYEE) WORKFLOW — Step by Step
================================================================================

STEP 1: AUTHENTICATION (LoginPage)
------------------------------------------------------------------------
  • User opens the portal and sees MoSPI / Government of India branding.
  • Enters credentials OR clicks the quick-demo button "Rahul (Officer)".
  • loginAs('employee') sets isLoggedIn = true and navigates to Dashboard.

STEP 2: DASHBOARD OVERVIEW (DashboardPage)
------------------------------------------------------------------------
  • Greeted with a personalized banner ("Good morning, Rahul").
  • Reviews 4 key KPI cards:
      - Overall Competency: 72%
      - Weekly Learning: 6.5 / 8.0 hrs
      - Courses Completed: 8 / 12
      - Current Skill Gaps: 4
  • Sees a 7-day weekly bar chart of daily study hours.
  • Views skill progress bars with trend indicators (e.g., Python +7%).
  • Previews top 3 AI-recommended courses.
  • Clicks "Weekly Progress Hub" or uses the DemoFlowBanner stepper.

STEP 3: WEEKLY PROGRESS AUDIT (WeeklyProgressPage)
------------------------------------------------------------------------
  • Reviews 7-day learning distribution:
      Mon: 0.8h | Tue: 1.2h | Wed: 0.6h | Thu: 1.5h
      Fri: 1.0h | Sat: 0.9h | Sun: 0.5h = 6.5 hrs total
  • Reads the AI Learning Insight card:
      - Praises statistical progress, notes Python +7%
      - Warns that SQL has a 19% gap needing attention
  • Clicks individual day bars to view specific activities completed.
  • Views course-wise time breakdown table and activity timeline.
  • Proceeds to Skill Gap Analysis via "Next Demo" button.

STEP 4: SKILL GAP DIAGNOSTICS (SkillGapAnalysisPage)
------------------------------------------------------------------------
  • Analyzes multi-axis Radar Chart showing Current Competency (blue)
    vs Required Benchmark (amber).
  • Reviews Priority Skill Gaps:
      HIGH PRIORITY:
        - SQL: 19% gap (Current 61% vs Required 80%)
        - AI/ML: 27% gap (Current 48% vs Required 75%)
      MEDIUM PRIORITY:
        - GIS: 15% gap (Current 55% vs Required 70%)
  • Clicks "Generate Learning Path" to get AI remediation steps.

STEP 5: PERSONALIZED LEARNING PATH (RecommendationsPage)
------------------------------------------------------------------------
  • Views a sequential AI-generated roadmap:
      Step 1: SQL Fundamentals (Immediate Priority)
      Step 2: SQL for Statistical Data
      Step 3: Data Analytics with Python (Currently Active)
      Step 4: Introduction to Machine Learning
  • Browses curated course cards with instructor details and ratings.
  • Explores external national training programs:
      - iGOT Karmayogi Bharat
      - NSSTA Greater Noida Academy
      - NDAP (NITI Aayog)
  • Clicks on a course card (e.g., Python) to view its syllabus.

STEP 6: COURSE SYLLABUS & LEARNING (CourseDetailPage)
------------------------------------------------------------------------
  • Views full course metadata:
      - Instructor, duration, difficulty, learning objectives.
  • Interacts with module curriculum:
      - Clicks module checkboxes to toggle completion.
      - Course progress bar dynamically recalculates.
  • Clicks the "Complete Quiz" call-to-action button.

STEP 7: INTERACTIVE ASSESSMENT (QuizPage)
------------------------------------------------------------------------
  • Takes a 10-question MCQ assessment on Official Statistics & Python.
  • Navigates between questions using Previous/Next buttons.
  • Question indicator pills show answered/unanswered status.
  • Clicks "Submit Assessment".
  • LIVE CASCADING TRANSFORMATION occurs:
      - Confetti explodes on screen!
      - Score banner: Python 68% → 72% (+4% increase)
      - Full question-by-question review with explanations displayed.
      - Behind the scenes, AppContext updates:
          * skills['Python'].current: 68% → 72%
          * skills['Python'].gap: 12% → 8%
          * overallCompetency: 72% → 74%
          * weeklyHours: 6.5h → 7.0h
          * Sunday hours: 0.5h → 1.0h
          * New quiz record prepended to history
          * New item prepended to activity timeline

STEP 8: VERIFICATION (Dashboard & WeeklyProgress — Revisit)
------------------------------------------------------------------------
  • Returns to Dashboard or Weekly Progress page.
  • Observes all metrics have been LIVE UPDATED:
      - Overall Competency: 72% → 74%
      - Weekly Learning: 6.5h → 7.0h
      - Python skill bar reflects 72% (was 68%)
      - Sunday hours updated to 1.0h (was 0.5h)
      - History table shows newly completed assessment
  • Confirms the closed-loop learning cycle is complete.

7. KEY FEATURES & PROTOTYPE HIGHLIGHTS
================================================================================

  1. STATEFUL REACTIVE LOOP
     Taking a quiz or toggling lessons instantly mutates global state,
     recalculating competencies, hours, timelines, and course progress
     across ALL screens in real-time.

  2. MoSPI / GOVERNMENT CADRE CONTEXTUALIZATION
     Authentic government terminology and structure: National Accounts
     Division, NSSO, NSSTA Academy, iGOT Karmayogi, NDAP, ISS cadres.

  3. MULTI-DIMENSIONAL VISUAL ANALYTICS
     Rich Recharts integrations: 7-day daily bar charts with target
     reference lines, radar charts for current vs required benchmarks,
     and multi-chart organizational dashboards.

  4. INTERACTIVE DEMO WALKTHROUGH (DemoFlowBanner)
     Built-in stepper guide allowing evaluators to step through the
     entire 6-stage demo story without getting lost:
       Dashboard → Weekly Progress → Competency Gap →
       AI Recommendations → Course Details → Assessment Quiz

  5. FAIL-SAFE PROTOTYPE RESET
     Sidebar "Reset Prototype State" button restores all metrics to
     baseline for repeated demonstrations.

  6. ACCESSIBLE & RESPONSIVE DESIGN
     Works seamlessly across mobile drawers, desktop viewports, with
     clean government-standard high-contrast color palettes.

  7. NATIONAL PLATFORM INTEGRATION
     Interoperability with Mission Karmayogi (iGOT), NSSTA, and
     NITI Aayog NDAP for comprehensive upskilling ecosystem.

8. HOW TO RUN THE PROJECT
================================================================================

  Prerequisites:
    • Node.js (v18 or later)
    • npm

  Steps:
    1. Install dependencies:
         npm install

    2. Start development server:
         npm run dev

    3. Open in browser:
         http://localhost:5173

    4. Build for production:
         npm run build

    5. Preview production build:
         npm run preview
