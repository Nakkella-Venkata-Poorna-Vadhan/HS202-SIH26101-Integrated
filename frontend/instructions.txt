Build a modern responsive web application prototype for an AI-enabled Learning and Competency Development Platform for India's Official Statistical System.

The purpose of this prototype is to demonstrate how an employee/officer can track their weekly learning progress, identify competency gaps, receive personalized learning recommendations, complete courses and quizzes, and improve their competency score over time.

This is a prototype for a Smart India Hackathon project. Focus on creating a polished, functional frontend with realistic dummy data. Do not try to implement the complete backend, real AI model, or actual iGOT Karmayogi API integration. Simulate these features with mock data.

PROJECT CONCEPT

The platform uses an employee's:
- Designation
- Department
- Job role
- Current assignment
- Educational qualifications
- Work experience
- Previous learning history
- Assessment performance
- Competency requirements

to identify competency gaps and recommend personalized learning.

The platform should visually demonstrate this workflow:

Employee Profile
      ↓
Competency Assessment
      ↓
Competency Score
      ↓
Skill Gap Identification
      ↓
Personalized Learning Recommendations
      ↓
Courses / Training
      ↓
Quizzes / Assessments
      ↓
Weekly Progress
      ↓
Improved Competency Score

PRIMARY USER

Employee / Government Official

Create a secondary Administrator dashboard as a prototype.

DESIGN STYLE

Create a professional government/enterprise SaaS dashboard.

Design requirements:
- Clean and modern UI
- Professional appearance
- White/light background
- Blue/navy primary color
- Subtle green accents for completed/improved items
- Red/orange indicators for competency gaps
- Rounded cards
- Minimal shadows
- Clear typography
- Responsive desktop and tablet layout
- Mobile responsive
- Accessible contrast
- Use icons where appropriate
- Avoid excessive animations

The design should feel suitable for a government learning platform, not like a gaming application.
